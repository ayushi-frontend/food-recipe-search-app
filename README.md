# 🍝 Meal Finder App

This is a simple **Meal Finder Web App** built using **HTML, CSS, and JavaScript**.  
The app allows users to search for food recipes and view meal images using the **TheMealDB API**.

## 🚀 Features

- Search meals by name
- Fetch real-time data from API
- Display meal image and name
- Responsive and clean UI
- Attractive food background

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- TheMealDB API

## 🔗 API Used

https://www.themealdb.com/api/json/v1/1/search.php?s=

## 📸 How It Works

1. Enter a food name in the search box
2. Click the search button
3. The app fetches meals from API
4. Meal image and name will be displayed
